# SHOPPING BY TUZIN

Каталог Coop, Conad, Lidl и Eurospin для просмотра товаров и составления корзины. В каталоге видны все товары, включая позиции без цены: у них серая неактивная кнопка корзины. В стандартном порядке товары с опубликованной ценой идут первыми внутри раздела. Раздел «Скидки / Offerte» показывает товары с явно указанной акцией или ценой по карте. Вкладка «ПП» собирает явно свежие овощи и фрукты, йогурты с сахаром и жирами до 5 г на 100 г, молоко с жирами до 1,5 г на 100 г/мл и напитки без сахара. Подборка чередует эти группы, а внутри групп учитывает доступные пищевые показатели. Это правило отбора каталога, не персональная рекомендация по питанию.

В сайдбаре показаны все родительские категории. Нажатие выбирает раздел и раскрывает его подкатегории, повторное нажатие сворачивает список. Подкатегория уточняет выбор; счётчики учитывают магазин, поиск и текущую вкладку. Повторное нажатие на выбранный магазин возвращает все магазины. При выборе раздела появляется сворачиваемая группа доступных характеристик: сахар, жиры, отсутствие сахара или лактозы. Блока «Цена» нет. Числовые фильтры включают только товары, для которых магазин опубликовал пищевую ценность. Кнопка «Показать ещё» добавляет следующую порцию товаров, сохраняя уже показанные. Состав и пищевая ценность читаются из сохранённых файлов проекта. Браузер запрашивает состав только с нашего сайта. Если записи ещё нет, сервер получает её у магазина по нажатию `i` и кеширует ответ.

Кнопка `i` открывает и закрывает состав и полную таблицу пищевой ценности на всю площадь карточки под шапкой магазина. Прокрутка остаётся внутри карточки; её размеры не меняются. Наведение не открывает информацию. Кнопка есть на каждой карточке и не зависит от наличия данных в кеше. Загрузка начинается после нажатия. Панель содержит состав, сведения об аллергенах и пищевую ценность со всеми опубликованными колонками. Основное название — русское, итальянское сохранено в данных и участвует в поиске. Магазин с микрологотипом расположен слева сверху. Компактный плюс справа от цены добавляет товар в корзину. После добавления на его месте показано количество; нажатие открывает корзину с кнопками «−» и «+». Высота карточки от добавления не меняется. Корзина группирует товары по магазинам и считает сумму в целых евроцентах по основной опубликованной цене. Цена по карте показана отдельно с условием и не подменяет сумму корзины. Зачёркнутые цены не вычисляются из процента скидки.

Интерфейс использует локальный вариативный Inter (лицензия в `assets/fonts/Inter-LICENSE.txt`), единую светлую палитру и компактные карточки с выравниванием цен через CSS subgrid. На телефоне панель каталога и сортировки остаётся доступна при прокрутке, категории открываются в боковой панели, выбранные характеристики можно убрать отдельными кнопками. Подкатегории и числовые фильтры остаются связанными с исходными данными.

## Локальный запуск

```bash
python -m pip install -r requirements.txt
python local_preview.py
```

Откройте `http://localhost:5173/`.

Проверки без сети: `python verify_cache.py`, `python verify_names.py`, `python verify_taxonomy.py` и `python verify_runtime_info.py`. Проверка публичных источников: `python verify_info.py` (для этих команд нужны зависимости из `requirements.txt`).

Проверки в браузере: `python verify_card_info.py` — состав и прокрутка; `python verify_catalog_ui.py` — цены, корзина, фильтры и адаптивный интерфейс. Нужны запущенный локальный сайт, Chrome и Python-пакет Playwright.

## Обновление каталога

```bash
python -m pip install -r requirements-translation.txt
python sync_catalog.py
python refresh_translations.py
python build_taxonomy.py
python refresh_attributes.py --limit 750 --max-seconds 600
```

GitHub Actions ежедневно в 03:17 UTC обновляет каталог, изображения и сохранённые характеристики (до 750 проверок, максимум 10 минут на состав), затем коммитит изменившиеся данные. Обновление можно запустить вручную в Actions → Refresh catalog → Run workflow. Для Vercel используется статический интерфейс и Python Function `api/info.py`; параметры функции заданы в `vercel.json`. Отдельный сервер для API не нужен: [Vercel поддерживает функции в `/api`](https://vercel.com/docs/functions/runtimes/python/api-directory).

Русские названия сохраняются в `name_ru` каждого товара и в `translations-ru.json`. Перед переводом скрипт удаляет служебные коды Coop. Существующие переводы используются повторно, новые названия переводятся локальными [моделями Argos](https://github.com/argosopentech/argospm-index) через CTranslate2. Модели загружаются один раз в `.translation-models/`, кэшируются в GitHub Actions и не публикуются с сайтом. При открытии каталога перевод не выполняется; неудачное обновление не публикует неполный набор названий.

`product-info-index.json` перечисляет готовые карточки и содержит версию снимка. Полный состав, аллергены и таблицы питания хранятся в 64 небольших файлах `data/product-info/*.json`; нужный файл загружается с того же сайта и повторно используется браузером. Индекс `product-attributes.json` строится из этих же данных и используется для фильтров. `product_sources.py` используется фоновым обновлением и серверной загрузкой недостающих составов. `/api/info?key=...` принимает только существующий ключ каталога; адрес магазина выбирается сервером. Успешные ответы сохраняются локально в `.runtime-info/` на 30 дней, пустой ответ — на час. Ошибки не записываются как отсутствие состава. На Vercel рабочий кеш функции временный, а ответы дополнительно [кешируются CDN](https://vercel.com/docs/caching/cache-control-headers); постоянный снимок остаётся в JSON проекта и обновляется ежедневно.

База пополняется постепенно: готовая карточка проверяется повторно через 30 дней, пустая — через 14 дней, недоступная — через 3 дня. Ошибка источника сохраняет последнюю успешную версию. Кнопка информации доступна у всех товаров: сначала используется сохранённый состав, затем — загрузка через наш сервер. Если сам источник не передал состав, панель сообщает об этом после запроса. Lidl не публикует эти данные в используемом источнике.

Coop и Conad обновляются из открытого среза [Spesa Viterbo](https://spesa-viterbo.vercel.app/), поскольку прямой запрос к Conad блокируется, а выбор конкретного магазина Coop без браузерного сеанса не подтверждён. Lidl Everli и Eurospin обновляются напрямую через их открытые каталоги. Для Lidl выбирается доступная зона обслуживания; для Eurospin цена Витербо не подтверждена. Выбор источников и условия цены поясняются на сайте.

Для большей части товаров Coop каталог использует изображения 598×598 с официального CDN вместо миниатюр 176×176. Для остальных сохраняется изображение из атласа. Ссылки на более крупные изображения обновляются вместе с каталогом.

Корзина хранится в браузере посетителя через `localStorage` и сохраняется после перезагрузки страницы. Избранного в интерфейсе нет.

`build_taxonomy.py` назначает каждому товару родительскую категорию и подкатегорию по исходному названию и пути каталога. Описания разделов хранятся в `catalog-taxonomy.json`, назначение — в `category` и `subcategory` товара. Неопознанная позиция остаётся в разделе «Другие товары раздела» своего родителя. Эта операция выполняется при ежедневном обновлении; браузер получает готовые данные.
