# SHOPPING BY TUZIN

Минималистичный каталог Coop, Conad, Lidl и Eurospin для просмотра товаров и сохранения избранного. Раздел «Скидки / Offerte» показывает товары с явно указанной акцией или ценой по карте; фильтр можно совместить с магазином и категорией. Кнопка «Показать ещё» добавляет следующую порцию товаров, сохраняя уже показанные. Кнопка `i` загружает состав и пищевую ценность из открытого источника Coop, Conad или Eurospin при нажатии. Корзины и оформления заказа нет.

## Локальный запуск

```bash
python -m pip install -r requirements.txt
python local_preview.py
```

Откройте `http://localhost:5173/`.

Проверка источников состава: `python verify_info.py`.

## Обновление каталога

```bash
python -m pip install -r requirements.txt
python sync_catalog.py
```

GitHub Actions запускает тот же скрипт ежедневно в 03:17 UTC и коммитит изменившиеся JSON и изображения. Обновление можно запустить вручную в Actions → Refresh catalog → Run workflow. Для Vercel выберите этот репозиторий без команды сборки; `api/info.py` разворачивается как Python Function. Новый коммит автоматически опубликует свежие данные.

Coop и Conad обновляются из открытого среза [Spesa Viterbo](https://spesa-viterbo.vercel.app/), поскольку прямой запрос к Conad блокируется, а выбор конкретного магазина Coop без браузерного сеанса не подтверждён. Lidl Everli и Eurospin обновляются напрямую через их открытые каталоги. Для Lidl выбирается доступная зона обслуживания; для Eurospin цена Витербо не подтверждена. Выбор источников и условия цены поясняются на сайте.

Для большей части товаров Coop каталог использует изображения 598×598 с официального CDN вместо миниатюр 176×176. Для остальных сохраняется изображение из атласа. Ссылки на более крупные изображения обновляются вместе с каталогом.

Избранное хранится только в браузере посетителя через `localStorage`.
