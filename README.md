# Spesa Viterbo

Статический продуктовый буклет Coop, Conad, Lidl и Eurospin. У каждой карточки есть магазин, цена и кнопка избранного. Корзины и оформления заказа нет.

## Локальный запуск

```bash
python -m http.server 5173
```

Откройте `http://localhost:5173/`.

## Обновление каталога

```bash
python -m pip install -r requirements.txt
python sync_catalog.py
```

GitHub Actions запускает тот же скрипт ежедневно в 03:17 UTC и коммитит изменившиеся JSON и изображения. Обновление можно запустить вручную в Actions → Refresh catalog → Run workflow. Для Vercel выберите этот репозиторий как статический сайт без сборки; новый коммит автоматически опубликует свежие данные.

Coop и Conad обновляются из открытого среза [Spesa Viterbo](https://spesa-viterbo.vercel.app/), поскольку прямой запрос к Conad блокируется, а выбор конкретного магазина Coop без браузерного сеанса не подтверждён. Lidl Everli и Eurospin обновляются напрямую через их открытые каталоги. Для Lidl выбирается доступная зона обслуживания; для Eurospin цена Витербо не подтверждена. Выбор источников и условия цены поясняются на сайте.

Избранное хранится только в браузере посетителя через `localStorage`.
