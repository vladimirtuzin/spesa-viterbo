# SHOPPING BY TUZIN

Каталог Coop, Conad, Lidl и Eurospin для просмотра товаров и сохранения избранного. Раздел «Скидки / Offerte» показывает товары с явно указанной акцией или ценой по карте. Вкладка «ПП» собирает явно свежие овощи и фрукты, йогурты с сахаром и жирами до 5 г на 100 г, молоко с жирами до 1,5 г на 100 г/мл и напитки без сахара. Подборка чередует эти группы, а внутри групп учитывает доступные пищевые показатели. Это правило отбора каталога, не персональная рекомендация по питанию.

В сайдбаре сразу показаны все родительские категории без раскрытия и вложенных типов. При выборе раздела появляется сворачиваемая группа доступных характеристик: сахар, жиры, отсутствие сахара или лактозы. Блока «Цена» нет. Числовые фильтры включают только товары, для которых магазин опубликовал пищевую ценность. Кнопка «Показать ещё» добавляет следующую порцию товаров, сохраняя уже показанные. Состав и пищевая ценность читаются из сохранённых файлов проекта. Запросы в магазины при просмотре карточки не выполняются.

На компьютере при наведении карточка раскрывает блок характеристик с отдельной прокруткой. Кнопка информации открывает полную таблицу и состав; на мобильном используется прокручиваемое окно. Магазин с микрологотипом расположен слева сверху. «Добавить в кошик» сохраняет товар в корзине; на карточке появляются кнопки количества. Корзина группирует товары по магазинам и считает сумму.

## Локальный запуск

```bash
python local_preview.py
```

Откройте `http://localhost:5173/`.

Проверки без сети: `python verify_cache.py` и `python verify_names.py`. Проверка публичных источников: `python verify_info.py` (для этих команд нужны зависимости из `requirements.txt`).

## Обновление каталога

```bash
python -m pip install -r requirements-translation.txt
python sync_catalog.py
python refresh_translations.py
python refresh_attributes.py --limit 750 --max-seconds 600
```

GitHub Actions ежедневно в 03:17 UTC обновляет каталог, изображения и сохранённые характеристики (до 750 проверок, максимум 10 минут на состав), затем коммитит изменившиеся данные. Обновление можно запустить вручную в Actions → Refresh catalog → Run workflow. Для Vercel достаточно статической публикации без команды сборки и Python Function.

Русские названия сохраняются в `name_ru` каждого товара и в `translations-ru.json`. Перед переводом скрипт удаляет служебные коды Coop. Существующие переводы используются повторно, новые названия переводятся локальными [моделями Argos](https://github.com/argosopentech/argospm-index) через CTranslate2. Модели загружаются один раз в `.translation-models/`, кэшируются в GitHub Actions и не публикуются с сайтом. При открытии каталога перевод не выполняется; неудачное обновление не публикует неполный набор названий.

`product-info-index.json` перечисляет готовые карточки и содержит версию снимка. Полный состав, аллергены и таблицы питания хранятся в 64 небольших файлах `data/product-info/*.json`; нужный файл загружается с того же сайта и повторно используется браузером. Индекс `product-attributes.json` строится из этих же данных и используется для фильтров. `product_sources.py` обращается к Coop, Conad и Eurospin только во время фонового обновления.

База пополняется постепенно: готовая карточка проверяется повторно через 30 дней, пустая — через 14 дней, недоступная — через 3 дня. Ошибка источника сохраняет последнюю успешную версию. Кнопка информации появляется только у товаров, для которых состав или пищевая ценность уже сохранены. Lidl не публикует эти данные в используемом источнике.

Coop и Conad обновляются из открытого среза [Spesa Viterbo](https://spesa-viterbo.vercel.app/), поскольку прямой запрос к Conad блокируется, а выбор конкретного магазина Coop без браузерного сеанса не подтверждён. Lidl Everli и Eurospin обновляются напрямую через их открытые каталоги. Для Lidl выбирается доступная зона обслуживания; для Eurospin цена Витербо не подтверждена. Выбор источников и условия цены поясняются на сайте.

Для большей части товаров Coop каталог использует изображения 598×598 с официального CDN вместо миниатюр 176×176. Для остальных сохраняется изображение из атласа. Ссылки на более крупные изображения обновляются вместе с каталогом.

Избранное и корзина хранятся в браузере посетителя через `localStorage` и сохраняются после перезагрузки страницы.
